## 跨阶段集成审核

### 问题 #6 (CRITICAL)：全局 _progress_callback 非并发安全

```
文件：app/engine/graph.py:66-67, 762, 1001

问题：_progress_callback 是模块级全局变量
     两个并发 WebSocket 辩论会互相覆盖回调
     事件可能发送到错误的 WebSocket 客户端

修复方案：
  用 contextvars.ContextVar 替代全局变量：
  
  import contextvars
  
  _progress_callback: contextvars.ContextVar[callable | None] = contextvars.ContextVar(
      '_progress_callback', default=None
  )
  
  async def _notify(event: dict):
      cb = _progress_callback.get(None)
      if cb:
          try:
              await cb(event)
          except Exception:
              pass
  
  # 在 run_debate_with_graph 中：
  _progress_callback.set(on_progress)
  ...
  _progress_callback.set(None)
```
